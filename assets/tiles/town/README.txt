Place your tile sprite sheet(s) here.

Recommended:
- Use a single sprite sheet named `magecity.png` (or update the path in `scenes/tiles/TownTiles.tres`).
- Tile size used in this project: 48x48 (adjust TileMap cell_size if you choose a different size).
- Each tile should be aligned on the grid (no extra padding) to simplify TileSet creation.

After adding the image, open Godot and edit `res://scenes/tiles/TownTiles.tres` to create autotile rules and collisions.
